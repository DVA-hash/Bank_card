# Проект Bank_card

## Описание:

в данном проекте идет разработка нового функционала для личного кабинета клиента
 
## Модуль masks

Модуль предоставляет функции для работы с банковскими операциями:

- `get_mask_card_number`: маскирует номера банковских карт.
- `get_mask_account`: маскирует номера банковского счета.

## Модуль widget

Модуль предоставляет функции для работы с банковскими операциями:

- `mask_account_card`: маскирует как номера карт так и номера счетов.
- `get_date`: преобразует строку с датой в формат "ДД.ММ.ГГГГ".

## Модуль processing

Модуль предоставляет функции для работы с банковскими операциями:

- `filter_by_state`: фильтрует операции по заданному состоянию.
- `sort_by_date`: сортирует операции по дате.
